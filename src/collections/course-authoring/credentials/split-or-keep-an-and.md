# Split or keep an "and"

## Learning targets

1. I can tell when "and" in a learning target joins two capabilities.
2. I can split a learning target that holds two capabilities.

## Task

Each learning target below has an "and". Some join a matched pair or two steps of one workflow, and are fine as they are. Others join two separate skills.

For each target, say keep or split. For a keep, give one line on why. For a split, write the two targets that replace it.

1. I can deploy a static site and explain how DNS resolution works.
2. I can archive and restore a course.
3. I can draft a team budget and submit it for approval.
4. I can write a unit test and review a teammate's pull request.
5. I can configure a reverse proxy and describe how TLS certificates are issued.
6. I can back up and restore a relay's database.

## Rubric

A split in other words passes when each half states one capability.

1. Split. "I can deploy a static site." and "I can explain how DNS resolution works." Deploying a site and explaining DNS are separate skills.
2. Keep. Archiving and restoring a course are a matched pair on one thing.
3. Keep. Drafting a budget and submitting it are two steps of one workflow.
4. Split. "I can write a unit test." and "I can review a teammate's pull request." Writing tests and reviewing code are separate skills.
5. Split. "I can configure a reverse proxy." and "I can describe how TLS certificates are issued." Setting up a proxy does not depend on explaining certificate issuance.
6. Keep. Backing up a database and restoring it are a matched pair.

Met when all six calls are right. Splitting a matched pair or one workflow fails the test.
