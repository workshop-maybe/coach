# Pick a lesson type

## Learning targets

1. I can match a learning target to the lesson type that teaches it best.
2. I can name the question that decides a close call between two lesson types.

## Task

An Andamio course teaches each learning target with one of five lesson types:

- Product demo: a walkthrough of a product's screens
- Developer documentation: code, an API or a library, with working examples
- How-to guide: a step-by-step procedure, often in a terminal or config files
- Organization onboarding: one organization's own setup, policies and conventions
- Exploration: concepts, trade-offs and the reasons behind a design

Pick the lesson type for each target below, with one line on why. For a close call, name the question that decided it.

1. I can change my notification settings in the team chat app.
2. I can call the payments API to refund an order.
3. I can renew a server's TLS certificate from the terminal.
4. I can request access to the company's shared drive.
5. I can compare a self-hosted relay to a hosted one.
6. I can assess a contributor's assignment. In this course, a project owner assesses work in the app, and the possible outcomes carry different consequences, some of them permanent.

## Rubric

1. Product demo. The learner needs to see where the setting is in the app.
2. Developer documentation. Code against an API is the main thing learned.
3. How-to guide. It is a terminal procedure with no product screens.
4. Organization onboarding. The process belongs to one company.
5. Exploration. It is a comparison of trade-offs, not a procedure.
6. Exploration. The assessing happens on screens, but the skill is judging which outcome fits and why the outcomes differ. The deciding question asks whether the learner needs to know why the system works this way, or only how to use it.

Met when all six calls are right and target 6 names its deciding question in any words. Calling target 6 a product demo fails the test.
