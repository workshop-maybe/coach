# Draft targets and an assignment for a module

## Learning targets

1. I can draft learning targets for a module from its topic and audience.
2. I can write one assignment that assesses every target in a module.

## Task

A design studio of eight people is moving to its first shared password manager. Write one module for the team.

Everyone on the team uses a browser and email every day. No one has used a password manager before. After the module, each person should keep their own logins and the team's shared logins in it.

Give:

- two to four learning targets, each in the "I can" form
- one assignment that assesses all of them, with what the learner hands in and how a reviewer judges it

## Rubric

- There are two to four targets. Each starts "I can" and uses a verb a reviewer can observe. "Understand", "know" and "learn" fail.
- Each target states one capability. None has a "by" clause, a list of items or a count.
- The targets fit the audience. They name what the team will do in the tool, without jargon.
- The assignment assesses every target, and the answer shows which part assesses which.
- The learner hands in something a reviewer can judge without watching, such as screenshots or a short written record. The assignment never asks for a real password.
- The details the targets leave out, such as how many logins to move, are in the assignment's criteria.

Met when every point holds.
