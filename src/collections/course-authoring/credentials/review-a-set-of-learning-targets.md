# Review a set of learning targets

## Learning targets

1. I can rate a learning target on each quality dimension.
2. I can leave a strong learning target alone.

## Task

Below are six learning targets from a short course on running a community forum. Target 1 opens the course, before the first hands-on step.

Rate each target on five dimensions: student-facing language, focus on learning, specificity, cognitive level and standalone clarity. Give each an overall rating of Strong, Acceptable or Needs Work. Rewrite any target that is not Strong, and leave the rest as they are.

1. I can find my way around the forum's admin panel.
2. I can understand how forum permissions work.
3. I can write a moderation policy for a forum.
4. I can ban a user by opening their profile, choosing Ban and entering a reason.
5. I can create at least three categories for a new forum.
6. The learner will configure email notifications for new posts.

## Rubric

- Target 1 is a light opener on purpose. The review may note its soft verb, but rates it Strong or Acceptable and does not rewrite it into something heavier.
- Target 2 is flagged for "understand", which cannot be observed, and the rewrite uses a verb that can, such as "explain".
- Target 3 is rated Strong with no rewrite. Inventing a problem in it fails the test.
- Target 4 is flagged for its "by" clause, a method that belongs in the lesson. The rewrite is "I can ban a user from the forum." or close to it.
- Target 5 is flagged for "at least three", a count that belongs in the assignment. The rewrite is "I can create categories for a new forum." or close to it.
- Target 6 is flagged as written for the teacher, and the rewrite uses the "I can" form.
- No rewrite adds a "by" clause, a list or a count.

Met when every point holds.
