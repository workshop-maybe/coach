This page follows one job from the paste to the routing record. Every request, match and file below is built by the app's own code from this scenario, each time the guide is built. Only Jev's answers are made up: the guide never asks TypeSafe, so its numbers are illustrative. [The router, end to end](/jev/router/) states each rule in full.

## The scenario

The folder has four badges: *Name what matters next*, *Say how sure you are*, *Check an answer key* and *Write a release note*, and two agents, Codex and Claude Code. Your cost order puts Codex first, as the cheaper.

- Claude Code holds *Say how sure you are*, met on September 26, and it is the badge's go-to. Codex's result there is Not met.
- Codex holds *Check an answer key*, met on September 27. Claude Code's reply there is only held, so it holds nothing yet.

## The steps in the app

1. On home, click <UI>Find an agent for a job</UI>.

<Shot id="router-door" alt="Home's three doors: Create an agent, Create a credential, and Find an agent for a job with an empty handoff card drawn on it" />

2. Under <UI>The job</UI>, paste the job and click <UI>Next</UI>. With Jev Mode on, the next card is <UI>Ask Jev which badge it's like</UI>, and it says what goes before anything is sent.

<Shot id="router-ask" alt="Ask Jev which badge it's like: Sends the job, and the names, tasks and learning targets of 4 badges, to TypeSafe, with the Ask Jev button and the Pick the badge myself link" />

3. Click <UI>Ask Jev</UI>. The card names Claude Code as <UI>Go-to for \{badge\}</UI>, here *Say how sure you are*, with when it met the badge, Jev's rating of the job, and *Check an answer key* under <UI>Also like:</UI>.

<Shot id="router-card" alt="The card for Claude Code: its setup, Go-to for Say how sure you are, Met on Sep 26, 2026, Jev rates this job routine, Also like: Check an answer key, and Take Claude Code" />

4. Checking each answer is half the job, so tap *Check an answer key* under <UI>Also like:</UI>. The card switches to that badge without asking again, and names Codex, the cheapest agent that holds it.

<Shot id="router-also" alt="The card for Codex after tapping Check an answer key: its setup, Cheapest agent holding Check an answer key, Met on Sep 27, 2026, Jev rates this job routine, Also like: Say how sure you are, and Take Codex" />

5. Click <UI>Take \{agent\}</UI>, here Take Codex. The app saves a routing record and goes home. You hand the job to Codex yourself.

The cost order behind the picks is set from home, under your agents, with <UI>Order by cost</UI>:

## The match

*Say how sure you are*, at 93%, is the strongest yes at 70% or more, so it is the match. *Check an answer key*, at 74%, is over the threshold too, so it is listed under <UI>Also like:</UI>. The other two are far below it.

## The rating

The expected level is 0.31 for needs judgment plus 0.10 for unusual or high-stakes: 0.41. That is below 0.5, so the job is routine, and the card won't step up.

<Example file="router/rating.json" caption="The levels, the expected level, and the rating" />

## The recommendation

For *Say how sure you are*, only Claude Code holds the badge cleanly, and it is the badge's go-to, so the card names it. For *Check an answer key*, only Codex holds it cleanly, and nobody is its go-to, so the card names the cheapest clean holder: Codex, first in your cost order.

Had Jev rated the job unusual or high-stakes, neither card would step up: no other agent holds either badge cleanly, so nothing ranks above the pick.
