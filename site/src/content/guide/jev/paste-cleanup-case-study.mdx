This page follows one paste from the clipboard to the joined reply. Every text and request below is built by the app's own code from this paste, each time the guide is built. Jev's answers are illustrative: the guide never asks TypeSafe. [The paste cleanup, end to end](/jev/paste-cleanup/) states each rule in full.

## The scenario

Claude Code takes *Write a release note* and writes a short one in the terminal. You copy it from the terminal window, so it comes with Claude Code's marker, the terminal's two-space margin, and sentences broken where the terminal wrapped them:

<Example file="cleanup/paste.txt" caption="The paste, as it comes off the clipboard" />

## The steps in the app

1. With Jev Mode on, test Claude Code on *Write a release note*: under <UI>Hand it over</UI>, click <UI>Copy</UI> and give Claude Code the handoff.
2. Copy its reply from the terminal and paste it into the box under <UI>What came back</UI>. The paste looks terminal-copied, so <UI>Clean up with Jev</UI> appears under the box.

<Shot id="jev-cleanup" alt="What came back with a reply pasted from a terminal, its sentences broken where the terminal wrapped them, and Clean up with Jev under the reply box" />

3. Click <UI>Clean up with Jev</UI>. The link reads <UI>Cleaning up…</UI> while Jev answers, and <UI>Next</UI> waits.
4. The wrapped lines are joined. <UI>Put back the paste</UI> appears in case you want the paste as it came. Click <UI>Next</UI> to judge the reply.

<Shot id="case-cleaned" alt="What came back after Clean up with Jev: the release note as three paragraphs with no broken sentences, and Put back the paste under the reply box" />

For the picture, the stand-in the guide uses for Jev answers every question 50%, which joins the same five breaks as the answers below.
